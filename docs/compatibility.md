# 互換性と意図的な差分

基準は [provenance](provenance.md) に固定した JavaScript `3.0.0-rc.2` と Swift の公開契約です。同一の安全なペイロード・セグメント・バージョン・ECC・マスクでは、行列とコードワードの一致を検証します。C# の戻り値・例外・名前は .NET 向けに定義しており、JavaScript オブジェクトとのバイナリ互換性や API 互換性は意味しません。

- 高水準 `Gs1` / `Fnc1Second` と生テキストのリテラル `%` は、`Auto` では Byte モードにして元のペイロードを保持します。明示的 `Alphanumeric` は曖昧なので拒否します。手動セグメントに高水準 FNC1 オプションを足す場合も、`%` を含む Alphanumeric を拒否します。これは基準 JavaScript の解釈によるデータ変更を避ける、Swift と共通の意図的な安全修正です。
- 低水準 `QRSegment.Fnc1()` / `Fnc1Second()` では、呼び出し側が QR Alphanumeric の FNC1 エスケープを管理します。`%` は GS、`%%` はリテラル `%` を表します。生の要素文字列とエスケープ済みの Alphanumeric 文字列を取り違えないでください。
- C# のテキストは Unicode スカラー単位で扱い、対応するペアのない UTF-16 サロゲートを拒否します。黙って置換文字に変えません。UTF-8 の Byte テキストと生の `byte[]` は区別します。
- ECI は割当番号を記録する制御セグメントです。文字列を任意の文字コードへ変換しません。UTF-8 テキストには割当番号 26 を指定してください。他の割当番号を使う場合は、その文字コードの生バイト列を呼び出し側で用意します。
- Canvas、Blob、Object URL、DOM は C# API にありません。代わりに SVG、PNG、data URL、移植可能なピクセルバッファを提供します。OS の UI との接続は利用者の UI フレームワークが担当します。
- 自動マスクのペナルティと同点時の選択は基準 JavaScript の方針です。別のエンコーダーの自動マスク選択との一致は要求せず、独立エンコーダーとの比較は固定条件で行います。
- PNG の圧縮バイト列、SVG の文字列レイアウトの完全一致は要求しません。画素の配置・寸法、色、メタデータ、安全性、復号したペイロードを検証します。
- 明示した資源上限、型で表せない入力、例外文言などは C# API 固有です。安全性の上限は [Structured Append](structured-append.md) と rendering 文書に記載します。

GS1 は限定した AI カタログのみです。Digital Link は決定的な処理を行う補助機能であり、GS1 全規格・全 AI・全業界制約の認証や、あらゆる URL の正規化を保証しません。Micro QR、rMQR、ロゴの重ね合わせ、装飾モジュール、QR リーダーは対象外です。

## Digital Link の dot path 値

GS1 の生の値として `.` / `..` 自体は有効ですが、URL パスに配置すると URL の dot-segment 正規化により修飾子が失われます。そのため `CreateDigitalLink` はパスに選んだ AI の値が `.` / `..` の場合に拒否します。`PathAis = Array.Empty<string>()` でクエリに配置すれば値を保持できます。これは基準 JavaScript にもあるデータ消失の経路を避ける意図的な差分です。生の値が `%2e` などの文字列の場合は `%` を通常どおりエンコードして保持します。
